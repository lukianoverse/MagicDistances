# Находилка расстояний между точками
Здесь представлено два варианта реализации считалки через интерфейсы.

Одна из них с большим количеством файлов, там для каждого _способа
определения расстояния_ отдельный файл с классом заведён. Запуск идёт
через [Main](./src/Main.java), а все служебные классы собраны 
в импровизированный пакет [math](./src/math).

Второй вариант обходится всего одним файлом [OneMeasure](./src/one/OneMeasure.java)
из пакета [one](./src/one), и там _способы_ передаются в метод просто
как лямбды.
